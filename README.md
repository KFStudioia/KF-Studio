# KF Studio - Inteligencia Artificial y Automatizacion

Centro digital oficial de KF Studio.

## Arquitectura y Funcionalidades
- Web SPA en modo oscuro con consultor KF Studio AI.
- Agendamiento inteligente con turnos (09:00-13:00 y 18:00-20:30) y buffer de 2 horas.
- Canales: Videollamada, Reunion Presencial y Llamada Telefonica.
- Base de datos en Supabase (tabla solicitudes_auditoria).
- Notificaciones en tiempo real via Make a Telegram Bot.
